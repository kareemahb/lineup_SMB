# Lineup | Walk-In Waitlist Landing Page
 
A one-page marketing site for **Lineup**, a concept SaaS product that lets walk-in businesses like barbershops, delis, and water ice stands run their waitlist by text. Customers text to join the line, see their spot, and get a text when they're up, so nobody has to crowd the waiting bench.
 
Built with plain HTML and CSS as part of my small business website series.
 
🔗 **Live Site:** [lineupsmb.netlify.app](https://lineupsmb.netlify.app/)

## ✨ What's on the Page
 
| Section | What it shows |
| --- | --- |
| **Navigation** | Logo, links to Features, How It Works, Pricing, and FAQ, plus Log in and Start free buttons |
| **Hero** | "The waitlist that texts your customers." with an email sign-up form and a phone mockup showing sample waitlist texts |
| **Logo strip** | Example local businesses using Lineup |
| **Features** | Three cards: customers just text, honest wait times, and rush-hour insights |
| **How It Works** | Three steps: claim your number, run the list from any browser, and tap to text the next customer |
| **Shop View** | A mockup of the owner's waitlist screen, with statuses like "Texted," "~26 min," and "In chair" |
| **Testimonials** | Three sample reviews from shop owners |
| **Pricing** | Three plans: Starter ($0), Shop ($29/mo, marked "Most popular"), and Block ($79/mo) |
| **FAQ** | Four expandable questions built with `<details>` |
| **Call to action and footer** | Final sign-up push, then Product, Company, and Support link columns |
 
---
 
## 🎨 Design
 
- **Product mockups built in HTML and CSS**: the phone texts and the shop's waitlist screen are coded, not screenshots
- **Native expand/collapse FAQ** with `<details>` and `<summary>`, so it works with no JavaScript
- **Responsive layout** with breakpoints at 950px and 700px for tablets and phones
- **Anchor navigation** that jumps to each section
---
 
## 🛠️ Tech Stack
 
- HTML5 (semantic sections, `<details>`)
- CSS3 (Flexbox, Grid, media queries)
- Hosted on **Netlify**
No JavaScript, frameworks, or build tools.
